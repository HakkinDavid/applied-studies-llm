DOCUMENTACIÓN DE main.py

Este archivo es el punto de entrada del backend.

Responsabilidades:
1. Crear la aplicación FastAPI.
2. Configurar CORS para permitir comunicación con el frontend.
3. Registrar los routers de la aplicación.
4. Mantener separada la lógica real en app/routes y app/services.

Routers:
- health: estado del backend.
- materials: subida y listado de materiales.
- questions: banco de preguntas y archivo compatible con el frontend.
- forest: bosque de conocimiento.
- frontend: entrega del frontend compilado.

Ejecución:
python -m uvicorn main:app --reload
